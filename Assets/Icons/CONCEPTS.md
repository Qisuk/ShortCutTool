# Icon Design Concepts

Visual concepts for ShortCutTool icon design. Choose one or mix elements!

## Concept 1: Keyboard Keys Stack 🎹

**Visual:** Three keyboard keys stacked vertically (Ctrl, Alt, Shift)

**Style:**
- White keys with subtle shadow
- Blue gradient background (#0078D4 → #005A9E)
- Keys show labels: "Ctrl", "Alt", "⇧"

**Pros:** Immediately recognizable, simple, keyboard-focused  
**Best for:** Users who think "keyboard shortcuts"

**AI Prompt:**
```
App icon showing three keyboard keys stacked vertically labeled Ctrl Alt 
and Shift, white keys with shadow on blue gradient background, flat 
minimal design, square icon format 512x512
```

- Light Gray: #E1E1E1

## Mix & Match Elements

Combine concepts for uniqueness:

- **Keys + Lightning:** Speed-focused keyboard
- **Windows + Keys:** Window management with shortcuts
- **Circuit + Keys:** Tech-savvy productivity tool
- **Rocket + Lightning:** Ultimate speed/launch combo
- **Monogram + Circuit:** Professional tech branding

---

## Size Testing Checklist

After generating, verify at these sizes:

- [ ] **256x256** - Windows 10/11, high DPI
- [ ] **48x48** - Desktop shortcut
- [ ] **32x32** - Taskbar
- [ ] **16x16** - System tray (MOST IMPORTANT)

Icon should be recognizable and not muddy at 16x16!

---

## Recommended: Start with Concept 2 (Lightning Keyboard)

**Why:**
1. ✅ Simple enough for 16x16
2. ✅ Clearly keyboard-related
3. ✅ Lightning suggests speed/shortcuts
4. ✅ High contrast (works on any background)
5. ✅ Unique but familiar

**Generate it first, then iterate if needed!**

---

## After Choosing

1. Generate 3-4 variations of your chosen concept
2. Pick the cleanest/simplest one
3. Test at small sizes
4. Convert and rebuild
5. Use for a day - see if it "feels right"
6. Iterate if needed (takes 5 minutes to swap!)

Remember: **Simpler is better** - the icon needs to work at 16x16 pixels!
